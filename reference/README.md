# Reference only

Do not copy code from this folder into the site. It is here so the team (and Claude Code) can look at earlier versions.

- `figma-dashboard/`: the Figma Make prototype of the app pages (React + Tailwind). Use it to see the page layouts, sections and content. Rebuild everything in plain HTML/CSS/JS.
- `trip-replay-first-version.html`: the first, standalone version of the 3D trip track (Bahasa Indonesia, with a table of all 20 trips). The current version lives inside `index.html`.
